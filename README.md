# Livro 3D para ela ❤️

Abra `index.html` no navegador. Para personalizar, edite o bloco `LIVRO` no topo do `<script>` (nomes, textos, cores, música) e coloque as fotos em `fotos/` (1.jpg, 2.jpg...).

Tipos de página: `texto`, `foto`, `fotos2` (duas fotos). Navegação: toque no livro, setas, teclado ou deslizar.

Para mandar o link: publique com GitHub Pages (Settings → Pages → branch) ou arraste a pasta em app.netlify.com/drop.
